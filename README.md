# BlenUtl

BlenderのトランスフォームデータをAviUtl2に書き出すアドオン、プラグインです。

通常のオブジェクト、ライトなどは `グループ制御`、カメラは `カメラ制御` としてAviUtl2にインポートできます。

:arrow_forward: **[紹介動画]()**

## インストール
1. [Releases](https://github.com/nullpo00/BlenUtl/releases) から `BlenUtl_1.0.0.zip` をダウンロードして展開
2. Blenderにアドオンをインストールする
    1. `Edit > Preferences... > Add-ons > Install from Disk...` から `export_aviutl_exedit2.py` を選択
    2. アドオン名左側のチェックボックスをオンにして有効化
3. AviUtl2にプラグインをインストールする
    1. `BlenUtl.au2pkg.zip`をAviUtl2のプレビュー画面へD&D
    2. `このプラグイン・スクリプトを信頼して使用する` を選択

## 使い方

### Blender側
- `File > Export` に `AviUtl ExEdit2 (.json)` が追加されます
    1. エクスポートしたいオブジェクトを選択する
    2. `File > Export > AviUtl ExEdit2 (.json)` から `.json` をエクスポートする

### AviUtl2側
- `ファイル > インポート` に `Blender (.json)` が追加されます
    1. `ファイル > インポート > Blender (.json)` を選択する
    2. Blenderでエクスポートした `.json` を選択してインポートする

## 設定項目

<details><summary>Blender</summary>

- エクスポートウィンドウ右側に設定項目一覧が表示されます
    - 表示されていない場合はキーボードの `Nキー` を押すと表示されます

| カテゴリ | 項目名 | 説明 |
| --- | --- | --- |
| Frame Range | N/A | オンにするとエクスポートする範囲をフレーム単位で指定できます<br>指定しない場合、アクティブシーンのFrame Rangeを使用します |
| | Start | 書き出す開始フレームを設定します |
| | End | 書き出す終了フレームを設定します |

---
</details>

<details><summary>AviUtl2</summary>

- `設定 > プラグイン設定 > BlenUtl` に設定項目が追加されます

| 項目名 | 説明 |
| --- | --- |
| 追加レイヤー | インポートオブジェクトを追加するレイヤーを設定します<br>0からの番号となります |
| 追加フレーム | インポートオブジェクトを追加するレイヤーを設定します<br>0からの番号となります |
| スケーリング係数 | Blenderの1メートル\(1BU\)をAviUtl2の何ピクセルに変換するかを設定します<br>例：250 -> Blenderで1m移動する場合AviUtl2では250px移動します |
| 拡大率のインポート方法 | BlenderのスケールをAviUtl2の拡大率へどのように変換するかを設定します<br>`X`：X軸の値を使用します<br>`Y`：Y軸の値を使用します<br>`Z`：Z軸の値を使用します<br>`平均`：X, Y, Zの平均値を使用します<br>座標系変換後の座標軸となります |
| カメラ視野角をインポートする | オンにするとカメラのインポート時にカメラ視野角をインポートします |
| 新規シーンにインポートする | オンにすると新規シーンを作成してインポートします<br>エクスポート時のBlenderのアクティブシーンに設定されている数値となります |
| 解像度をインポートする | オンにすると解像度をインポートします<br>エクスポート時のBlenderのアクティブシーンに設定されている数値となります |
| フレームレートをインポートする | オンにするとフレームレートをインポートします<br>エクスポート時のBlenderのアクティブシーンに設定されている数値となります |

---
</details>

## 補足
- Blenderで複数のオブジェクトを選択してエクスポートした場合、アクティブオブジェクトのデータのみエクスポートされます
- Blenderでオブジェクトにペアレント、コンストレイント、ドライバーを設定している場合でも、実際にエクスポートしたいオブジェクトを選択してください
    - 例：`エンプティ(親) -> カメラ(子)` となっていて、カメラをエクスポートしたい場合はエンプティではなくカメラを選択してください
    - グローバル座標\(絶対座標\)で書き出します
- インポートオブジェクトがにすでにタイムライン上に配置されているオブジェクトと重なる場合、インポートに失敗します
- カメラ上方向ベクトルを設定するためのカメラ制御用スクリプト `CameraUp@BlenUtl` も同時に追加されます
    - カメラ上方向ベクトルを制御するためのスクリプトとして、個別で使用することもできます
- カメラ視野角の数値は正確ではありません
    - AviUtl2の仕様上カメラ視野角の細かい設定ができないので、個別で調整することをおすすめします
